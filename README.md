# Jira QA Project – Online Shop

## Project Overview

This project demonstrates the use of Jira for managing QA activities within an Online Shop web application.

The project includes test tasks, bug reports, issue tracking, and Agile workflow management. It focuses on validating key e-commerce functionalities and documenting defects throughout the testing process.

## Features

* Test case management
* Bug reporting and tracking
* Issue prioritization
* Sprint and backlog organization
* Agile/Scrum workflow management
* Documentation of test results and defects

## Project Scope

The Jira board covers testing activities related to:

* User authentication
* Product browsing
* Shopping cart functionality
* Checkout process
* Password recovery
* General website functionality

## Tools Used

* Jira
* Manual Testing
* Agile / Scrum Methodology

## Learning Objectives

This project was created to practice:

* Defect reporting and tracking
* Test management
* Agile project workflows
* QA documentation
* Software testing processes
